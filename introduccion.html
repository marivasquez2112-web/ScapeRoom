🧪 El misterio del laboratorio 🧪

Todo comenzó cuando un grupo de estudiantes entró al laboratorio de ciencias para terminar un proyecto.

Al principio todo parecía normal, pero de repente las luces se apagaron y una computadora comenzó a mostrar un extraño mensaje.

"⚠️ LABORATORIO BLOQUEADO ⚠️"

Cada respuesta correcta les dará una pista para descubrir el código final. Pero cuidado... una respuesta incorrecta podría alejarlos de la salida.
